# Icarus 솔로 편의 조정

**현재 배포 상태: 소스만 보관. 자동 승인 검토가 실행 패키지 생성 및 로컬 실행 명령을 차단하여, 즉시 실행 가능한 패키지는 아직 제공하지 못했다. 아래 사용법은 패키징 완료 후의 예정 사용법이다. UI 및 실제 게임 적용 검증 미완료.**

사용자의 소폭 조정 요청에 맞춘 재시작 적용형 프로그램. `Start.vbs`를 더블클릭하면 기본 브라우저에서 열린다. 인터넷 서버가 아니라 이 PC의 임시 localhost 서버를 사용하며 외부 요청이나 원격 접속을 받지 않는다. 앱 내부 **프로그램 종료**로 서버도 종료한다(30분 미사용 시 자동 종료).

1. 게임과 전용 서버를 정상 종료한다.
2. 프로그램 실행 → `가볍게` 또는 개별 슬라이더 선택.
3. 싱글 전용 확인 후 `설정 적용`. 변경 직전 현재 모드 상태를 백업한다.
4. 게임을 다시 실행하고 싱글월드에서 확인한다.
5. 멀티플레이 전 게임 종료 → 이 앱에서 `모드 해제`.

체력/스태미나/무게 기본값은 +0~25%, 이동속도 기본값은 +0~10%. 현재 음식/장비/재능을 포함한 최종값을 고정하는 기능이 아니다. 소폭 변경은 감지 회피나 계정 제재 면제를 보장하지 않는다.

원본 data.pak, 캐릭터 세이브, 경험치, 재능, 기존 HUD와 UE4SS 파일은 변경하지 않는다. 적용 대상은 `Icarus/Content/Paks/mods/997-IcarusSoloComfort_P.pak` 하나뿐이다. 기술적으로 특정 월드나 캐릭터에 한정하지 않으며 이후 멀티 접속을 차단하지도 않는다. 실시간 변경·인증/탐지 우회·무적·무한 자원 없음. 이전의 XP/재능 편집 요청은 소폭 편의 조정 방향으로 축소하면서 이번 버전에서 제외했다.

## 백업과 복구

`%LOCALAPPDATA%/IcarusSoloComfort/backups`에 적용/해제 직전 모드와 기록을 보관한다. 세이브 백업은 아니다(세이브를 수정하지 않는다). 다른 게임 버전의 모드 백업은 복원을 거절한다. 게임이 업데이트되면 앱에서 모드를 해제하거나 현재 데이터로 다시 생성한다. 다른 모드가 동일 테이블을 사용하거나 패키지를 읽지 못하면 적용을 차단한다. 완전한 모든 종류의 모드 충돌 탐지는 아니다.

앱이 강제 종료돼 `write.lock`이 남은 경우, IcarusSoloComfort 서버 프로세스가 더 이상 실행 중이 아닌 것을 확인한 후 해당 파일만 제거하고 다시 실행한다. 파일 접근 권한 오류는 오류로 표시하며 관리자 권한을 자동 요청하지 않는다. 게임 실행 검사 직후 사용자가 게임을 동시에 시작하는 경쟁 조건을 OS 수준으로 봉쇄하는 것은 아니므로 적용 중 게임을 시작하지 않는다.

## 설치 경로 / 개발

Steam libraryfolders.vdf로 설치 위치를 찾는다. 필요하면 `SOLO_TUNER_GAME`에 Icarus 최상위 설치 경로를 지정해 `node server.cjs` 실행. 개발용 `SOLO_TUNER_STATE`는 별도 상태 폴더, `--no-open`은 브라우저 자동 열기 방지다. 실행 패키지에는 Node와 repak 0.2.3을 포함할 예정이다. 소스 저장소에는 외부 실행 파일을 커밋하지 않는다.

검사: `node --test test.cjs`. `SOLO_TEST_REPAK` 환경 변수로 repak.exe를 지정하면 가상 설치 폴더에서 실제 패키지 생성·별도 리더 검증·해제·복원 시험을 한다. 실제 사용자 설치본/세이브에 시험 적용하지 않는다.

## 근거와 한계

- 설치된 data.pak의 D_CharacterStartingStats.json을 읽어 네 항목만 수정한다.
- [IcarusModManager 구현](https://github.com/CrystalFerrai/IcarusModManager/blob/main/IcarusModManager.Core/ModManager.cs)의 데이터 모드 mount point `../../../Icarus/Content/data/`를 확인했다.
- [repak](https://github.com/trumank/repak) v0.2.3으로 V11 비압축 패키지 생성 후 기존 프로젝트의 독립 PAK 리더로 경로/내용을 확인한다.
- [WeMod Icarus](https://www.wemod.com/ko/cheats/icarus-trainers)의 실시간 기능 존재를 확인했으나 내부 구현·감지 회피·제재 면제를 검증한 것이 아니다. [WeMod 정책](https://www.wemod.com/policies)은 경쟁 멀티플레이용 모드 제작을 하지 않는다고 명시한다.
- 실제 게임 내 반영과 장시간 안정성은 미검증. 파일 적용 성공과 실게임 확인은 별개다.
