# 아이카루스 싱글 도구 0.4.3

0.4.3: 재능 포인트를 빼는 것도 가능(-30 ~ +60). 솔로 포인트는 게임 데이터 표가 아니라 곡선 파일이라 이 방식으로는 바꿀 수 없습니다.

0.4.2: ‘텔레포트’ 탭. 게임을 켠 채로 지금 위치 저장 → 저장한 장소로 이동 → 이동 전 위치로 복귀. 싱글 월드·같은 지도·지도 범위 안에서만, 도착은 1.5m 위. 이 도구에만 있고 HUD에는 없습니다.

0.4.1: F11 없이 ‘가방으로 바로 받기’를 누르면 1~2초 안에 지급(모드가 1초마다 요청 파일만 확인, 요청이 있을 때만 게임 작업). F11도 그대로 동작. 모드 갱신을 위해 게임을 한 번 끄고 앱을 켠 뒤 다시 시작하세요.

0.4.0: 체력 최대 10배, 새 탭 ‘동물 번식’(길들인 동물 임신 기간·새끼 자라는 시간 10~100%).

0.3.9: 이미 적용한 설정을 다시 적용할 때 자기 파일을 '다른 모드와 겹침'으로 잘못 막던 문제 수정.

0.3.8: 재능 포인트 탭. 게임이 주는 재능 포인트에 +0~60을 더합니다(게임 종료 후 ‘설정 적용’).

0.3.6: 금빛 날개 앱 아이콘. 프로그램 창/작업 표시줄/바탕화면 실행기에 같은 아이콘을 적용하며 이후 업데이트 때 본 도구의 바탕화면 실행기도 함께 갱신합니다.

바탕화면의 **아이카루스 싱글 도구.exe**를 열어 사용합니다. 앱 본체는 `%LOCALAPPDATA%/Programs/IcarusSoloTools`에 설치됩니다. 바탕화면 파일은 별도의 작은 실행기이므로 본체가 업데이트되어도 그대로 사용할 수 있습니다.

## 수치 조절: 고르기 → 설정 적용 → 게임 시작
- 체력: 기본 최대 체력 1~10배.
- 스태미나: 달리기·점프·도구 사용 비용. 기본 / 절반 / 소모 없음.
- 생존: 산소 소모, 배고픔 진행, 목마름 진행을 각각 선택.
- 무게: 가방에 들 수 있는 무게 한도 1~5배. 개별 아이템 무게는 그대로입니다.
- 내구도: 도구·무기·방어구 최대 내구도 1~5배. 현재 내구도를 채우는 수리 기능은 아닙니다.
- 달리기: 달리기 속도 1~2배. 걷기 속도는 그대로입니다.
- 동물 번식: 길들인 동물의 임신 기간(`GestationPeriodSeconds`)과 새끼가 자라는(길들이는) 시간(`TameDurationInSeconds`)을 원래의 10~100%로. `AI/D_Tames.json`.
- 재능 포인트: 캐릭터 재능 포인트 -30~+60. 게임 데이터 `D_PlayerTalentModifiers`에 조건 없는 보너스 한 줄을 더하는 방식이며, 레벨·청사진 포인트는 바꾸지 않습니다. 줄이거나 끄기 전에는 게임에서 재능을 먼저 초기화하세요.

탭에서 버튼을 누르거나 슬라이더를 움직인 다음 **설정 적용**을 누릅니다. 다른 탭의 선택도 함께 저장됩니다. 게임이 켜져 있으면 적용하지 않습니다. **모두 기본값 → 설정 적용**으로 원복합니다. 적용 전 자신의 기존 모드를 백업합니다.

싱글플레이용 데이터 모드입니다. 멀티플레이에 들어가기 전 모두 기본값으로 복원하세요. 기본 수치에 음식·장비·재능이 더해질 수 있어 화면의 최종 능력치는 달라질 수 있습니다.

## 아이템 생성
1. 게임을 종료하고 아래 **모드 설치 / 갱신**을 누릅니다. 기존 길동무의 UE4SS를 공유하며 로더 설정은 바꾸지 않습니다.
2. 게임을 켜고 싱글 월드에 들어갑니다.
3. 아이템을 검색하고 수량을 고른 뒤 **가방으로 바로 받기**를 누릅니다.
4. 게임 화면으로 바꿀 필요 없이 1~2초 안에 가방에 들어옵니다(F11도 계속 사용 가능).

처음에는 돌 1개로 시험하세요. 함수 호출 완료와 실제 지급 성공은 별개입니다. 실제 가방에서 확인해야 합니다. 2,989개 템플릿을 제공하며 게임 업데이트에 따라 지원 목록이 달라질 수 있습니다.

## 자동 업데이트
기본으로 켜져 있습니다. 시작할 때와 15분마다 새 버전을 확인하고 다운로드합니다. ZIP 크기·SHA256, 내부 모든 파일의 경로·크기·SHA256 검증 후 게임이 꺼져 있고 설정을 편집 중이지 않을 때 앱을 다시 시작하며 교체합니다. 작업 중이면 기다립니다. 파일 교체 실패 시 기존 파일로 복원합니다.

설정은 `%LOCALAPPDATA%/IcarusSoloTools`에 별도로 보관됩니다. 업데이트 실패 시 기존 버전을 계속 사용할 수 있습니다. 설정 탭에서 자동 업데이트를 끄거나 수동 확인할 수 있습니다. 배포 주소는 이 프로젝트의 `codex/solo-items` 브랜치 `standalone/manifest.json`이며, 배포 완료된 버전만 받습니다.

## 길동무와 함께 사용
- 독립 .NET Windows 앱입니다. Electron/웹 서버/상시 게임 메모리 스캔을 추가하지 않습니다.
- 별도 `IcarusSoloItems` 모드, `998-IcarusSoloTools_P.pak`, 전용 사용자 설정 폴더를 사용합니다.
- 기존 HUD의 파일·설정·업데이트 채널을 수정하지 않습니다. 아이템 생성은 F11 요청 때만 게임 객체에 접근합니다.
- 수치 적용 전에 다른 PAK가 같은 데이터 테이블을 바꾸는지 확인하고 중복 시 중단합니다.
- 데이터 모드 적용·해제는 게임/서버가 종료된 경우에만 허용합니다.

## 검증과 한계
실제 설치 게임 데이터를 읽어 가짜 게임 폴더에서 PAK 생성·읽기·원복, 실행 중 차단, 외부 변경 보호를 시험했습니다. 업데이트 패키지 검증·교체·중간 실패 원복·잘못된 경로 차단도 시험했습니다. 이는 실제 게임 플레이, 모든 기존 모드와의 호환성, FPS 무영향을 보장하는 시험은 아닙니다. 신규 수치와 아이템 지급의 인게임 결과는 아직 확인이 필요합니다.

개발 빌드: `powershell -NoProfile -ExecutionPolicy Bypass -File Build.ps1`
검사: `IcarusSoloItems.exe --self-test`, `--suite-test`; Lua 모의 검사 `node --test test.cjs` (fengari 필요).

PAK 도구: [trumank/repak v0.2.3](https://github.com/trumank/repak) (MIT OR Apache-2.0). 라이선스는 tools 폴더에 포함됩니다.

창 모서리를 드래그해 크기를 조절할 수 있습니다. 기본 화면은 980×650이며, 마지막으로 조절한 크기를 기억합니다. 최대화/복원도 지원합니다.

상단 ONLINE은 해당 게임 모드의 최신 응답을 뜻합니다(아이템 지급 보장은 아님). WAITING은 게임 실행 중 응답 대기, OFFLINE은 미실행/미설치/확인 실패입니다. 싱글 월드에서 F11을 누르면 사용 준비를 확인합니다. 요청이 있다면 F11은 그 요청도 실행합니다. 확인 결과는 10초 후 만료됩니다. 체력 등 조절은 여전히 게임 종료 후 적용하고 재실행해야 합니다.

0.3.6: 직접 연 월드에서 혼자 플레이하는 호스트도 허용합니다. 로컬 호스트 권한·활성 플레이어 1명·관전자 0명을 확인하며, 다른 서버 접속이나 여러 명인 월드는 차단합니다. 게임 실행 중에는 모드를 교체하지 않으므로 종료 후 업데이트하고 재실행해 주세요.

0.3.6: 요청당 최대 1,000개, 수량 버튼 1/100/500/1000. F11 한 번으로 25개씩 100ms 간격 분할 호출합니다. 진행 중 요청 중지/취소 가능, 이미 처리한 아이템은 회수하지 않습니다. 월드·캐릭터·접속 인원이 바뀌거나 처리 30초를 넘으면 중단합니다. 호출 수는 실제 가방 지급 수량을 보장하지 않습니다.


## 아이템 이미지
목록 썸네일과 선택한 아이템 미리보기를 제공합니다. 2,989개 중 2,155개는 기존 게임 아이콘과 연결했고, 나머지 834개는 ‘이미지 준비 중’으로 표시합니다. 이미지는 앱에 포함되어 인터넷 없이 표시됩니다.


## 분류와 추천 제작 세트
검색 아래 분류에서 재료·도구/무기·방어구/가방·음식·의약품·건축·설비·농사/동물·기타를 고릅니다. 검색어와 분류를 함께 사용할 수 있습니다.
‘추천 제작 세트’에서 기초 공방, 목공, 석공, 방어구, 약초, 가공, 전자 제작용 재료를 고르고 세트 수를 조절합니다. 재료 구성과 합계를 확인한 뒤 ‘세트 요청 준비’ → 게임에서 F11. 완성품이 아닌 기본 레시피 재료이며 청사진/작업대는 별도, 보유량과 재능 할인은 미반영입니다. 전체 합계 최대1,000개, 중간 취소 가능.


## 아이템 설명과 기본 스탯
아이템을 선택하면 짧은 설명이 표시됩니다. ‘설명 · 스탯’을 누르면 전체 설명과 기본 수치를 볼 수 있습니다. 게임 한국어 설명2,042개, 설명이 없는947개는 ‘분류 기반 안내’로 구분합니다. 도구130종의 확인된 기본 피해/채집 효율과 내구도 등을 표시하며, 재능·개조·현재 도구 설정이 반영된 실시간 장비 수치는 아닙니다.
