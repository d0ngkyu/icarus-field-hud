# 아이카루스 싱글 도구 0.3.0

바탕화면의 **아이카루스 싱글 도구.exe**를 열어 사용합니다. 앱 본체는 `%LOCALAPPDATA%/Programs/IcarusSoloTools`에 설치됩니다. 바탕화면 파일은 별도의 작은 실행기이므로 본체가 업데이트되어도 그대로 사용할 수 있습니다.

## 수치 조절: 고르기 → 설정 적용 → 게임 시작
- 체력: 기본 최대 체력 1~3배.
- 스태미나: 달리기·점프·도구 사용 비용. 기본 / 절반 / 소모 없음.
- 생존: 산소 소모, 배고픔 진행, 목마름 진행을 각각 선택.
- 무게: 가방에 들 수 있는 무게 한도 1~5배. 개별 아이템 무게는 그대로입니다.
- 내구도: 도구·무기·방어구 최대 내구도 1~5배. 현재 내구도를 채우는 수리 기능은 아닙니다.
- 달리기: 달리기 속도 1~2배. 걷기 속도는 그대로입니다.

탭에서 버튼을 누르거나 슬라이더를 움직인 다음 **설정 적용**을 누릅니다. 다른 탭의 선택도 함께 저장됩니다. 게임이 켜져 있으면 적용하지 않습니다. **모두 기본값 → 설정 적용**으로 원복합니다. 적용 전 자신의 기존 모드를 백업합니다.

싱글플레이용 데이터 모드입니다. 멀티플레이에 들어가기 전 모두 기본값으로 복원하세요. 기본 수치에 음식·장비·재능이 더해질 수 있어 화면의 최종 능력치는 달라질 수 있습니다.

## 아이템 생성
1. 게임을 종료하고 아래 **모드 설치 / 갱신**을 누릅니다. 기존 길동무의 UE4SS를 공유하며 로더 설정은 바꾸지 않습니다.
2. 게임을 켜고 싱글 월드에 들어갑니다.
3. 아이템을 검색하고 수량을 고른 뒤 **생성 요청 준비**를 누릅니다.
4. 2분 이내에 게임으로 돌아가 **F11**을 누릅니다.

처음에는 돌 1개로 시험하세요. 함수 호출 완료와 실제 지급 성공은 별개입니다. 실제 가방에서 확인해야 합니다. 2,989개 템플릿을 제공하며 게임 업데이트에 따라 지원 목록이 달라질 수 있습니다.

## 자동 업데이트
기본으로 켜져 있습니다. 시작할 때와 15분마다 새 버전을 확인하고 다운로드합니다. ZIP 크기·SHA256, 내부 모든 파일의 경로·크기·SHA256 검증 후 게임이 꺼져 있고 설정을 편집 중이지 않을 때 앱을 다시 시작하며 교체합니다. 작업 중이면 기다립니다. 파일 교체 실패 시 기존 파일로 복원합니다.

설정은 `%LOCALAPPDATA%/IcarusSoloTools`에 별도로 보관됩니다. 업데이트 실패 시 기존 버전을 계속 사용할 수 있습니다. 설정 탭에서 자동 업데이트를 끄거나 수동 확인할 수 있습니다. 배포 주소는 이 프로젝트의 `codex/solo-items` 브랜치 `standalone/manifest.json`이며, 배포 완료된 버전만 받습니다.

## 길동무와 함께 사용
- 독립 .NET Windows 앱입니다. Electron/웹 서버/상시 게임 메모리 스캔을 추가하지 않습니다.
- 별도 `IcarusSoloItems` 모드, `998-IcarusSoloTools_P.pak`, 전용 사용자 설정 폴더를 사용합니다.
- 기존 HUD의 파일·설정·업데이트 채널을 수정하지 않습니다. 아이템 생성은 F11 요청 때만 게임 객체에 접근합니다.
- 수치 적용 전에 다른 PAK가 같은 데이터 테이블을 바꾸는지 확인하고 중복 시 중단합니다.
- 데이터 모드 적용·해제는 게임/서버가 종료된 경우에만 허용합니다.

## 검증과 한계
실제 설치 게임 데이터를 읽어 가짜 게임 폴더에서 PAK 생성·읽기·원복, 실행 중 차단, 외부 변경 보호를 시험했습니다. 업데이트 패키지 검증·교체·중간 실패 원복·잘못된 경로 차단도 시험했습니다. 이는 실제 게임 플레이, 모든 기존 모드와의 호환성, FPS 무영향을 보장하는 시험은 아닙니다. 신규 수치와 아이템 지급의 인게임 결과는 아직 확인이 필요합니다.

개발 빌드: `powershell -NoProfile -ExecutionPolicy Bypass -File Build.ps1`
검사: `IcarusSoloItems.exe --self-test`, `--suite-test`; Lua 모의 검사 `node --test test.cjs` (fengari 필요).
