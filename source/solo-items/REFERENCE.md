# 사용자 참고 자료 및 범위

2026-11-14 사용자: 개인용, 이 PC에서 혼자 사용. 길동무와 독립, 가벼운 앱, 간단한 버튼/탭. 바탕화면 exe 및 이후 자동 업데이트 요청.

사용자 제공 https://www.wemod.com/ko/cheats/icarus-trainers 페이지를 직접 확인했다. 플레이어/인벤토리/물리 등의 분류와 켜기/끄기 조작을 참고한다. 페이지는 무한 체력/스태미나/산소, 허기/갈증 제거, 무한 무게/내구도, 초고속 등 23개 기능을 안내한다. 설명만으로 WeMod의 내부 구현/API를 확인한 것은 아니다.

현재 0.3.0 범위는 앞서 요청한 항목의 종료 후 적용형 데이터 모드다. 체력은 최대치 증가이며 무적이 아니다. 무게는 휴대 한도 증가이며 완전 무제한이 아니다. 내구도는 장비 최대치 증가이며 소모 방지/현재 내구도 수리가 아니다. 소모량 0은 해당 기본/행동 비용을 0으로 만든다는 뜻이며 다른 모든 게임 효과를 막는다고 주장하지 않는다. 사용자가 요청하지 않은 비행/XP/포인트/시간 변경은 이번 범위가 아니다.

추가 실시간 기능을 원하면 최신 SDK와 게임 안정성을 별도로 조사하며 현재 기능을 이미 실시간인 것처럼 표시하지 않는다. 사용자에게 외부 AI로 기술 전달을 요구하지 않는다.
