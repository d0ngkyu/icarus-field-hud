# Item descriptions and tool stats · 0.3.7

- Every catalog item has a short description: 2,042 exact Korean D_Itemable localization matches; 947 explicitly labelled category-based guidance where localized descriptions were absent. We do not fabricate individual item effects. Embedded `assets/details.json` records the source label.
- Read-only extraction from installed data.pak: D_ItemsStatic links Itemable, ToolDamage and Durable rows. Defaults merge only into an existing referenced row. Korean text uses the project's local Game.locres JSON extracted 2026-11-16. BuildDetails records SHA256 of each table and the localization JSON; full source localization is not redistributed here.
- 130 item templates have referenced D_ToolDamage. Display only present positive damage/efficiency fields; efficiency shown as a multiplier, not interpreted as extra percent. Example Stone_Pickaxe: melee30 ±10%, mining1x, max durability20,000. Titanium_Pickaxe: melee55 ±10%, mining1.4x, max durability120,000. Native/raw mining radius and uncertain weight-unit conversions intentionally omitted.
- Referenced durable items also show base max durability; valid Itemable rows show base stack limit. These are base table values, not live equipment stats, not adjusted for talents/alterations/mods/this tool's tuning. Ranged/projectile damage combinations and every possible special effect are not claimed to be covered.
- Main selection shows brief text and a “설명 · 스탯” button. Detail dialog contains full text, source, verified stat rows and base-value notice. Dialog blocks updater application while open, but never touches game objects or generates items. Images/descriptions/categories/sets are embedded resources; no startup web requests added.
- Build: `node tools/BuildDetails.cjs <table directory> <Korean JSON>` after category library generation. C# `--details-test`: all2989 nonempty descriptions, provenance, known Stone/Titanium values, material distinction, two-size layout and offscreen render. Render found the Korean header too short; expanded from32px to44px and visually rechecked. Actual in-game modified stat matching and FPS not verified.
